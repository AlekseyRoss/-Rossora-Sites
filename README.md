# Rossora Sites ☕
rossora.dn.ua
Современный адаптивный сайт Rossora Sites.

## 🌐 О проекте

Rossora Sites — это современный веб-сайт, созданный для представления услуг по разработке сайтов, портфолио проектов и информации о компании.

Основной акцент проекта:
- современный премиальный дизайн;
- адаптивность под компьютеры, планшеты и мобильные устройства;
- плавные анимации;
- удобная навигация;
- поддержка нескольких языков.
